# Adversarial Validation Protocols

Sources: Military red teaming, Kahneman (adversarial collaboration),
Weinstein (Russell Conjugation), Page (Diversity Prediction Theorem),
Friston (Active Inference / Free Energy Principle), Fuller (CADS).
Adapted for worldbuilding canon enforcement.

---

## 1. Intellectual Red Teaming

Origin: military strategy and cybersecurity. An independent, hostile team
simulates an adversary to discover vulnerabilities before real attack.

**Worldbuilding protocol:** Before accepting any new lore element, construct
the strongest possible argument AGAINST it. Not devil's advocate — genuinely
hostile deconstruction.

Steps:
1. State the new element precisely
2. List every foundational constraint it must satisfy
3. For each constraint: construct the most lethal argument for violation
4. For each argument: can it be refuted with specific evidence?
5. If ANY argument survives refutation: the element fails

**Escalation ladder:**
- Level 1: Does it contradict any explicit rule?
- Level 2: Does it contradict any implicit constraint (downstream implications)?
- Level 3: Does it survive cross-civilization application?
- Level 4: Would a hostile reader find it inconsistent?
- Level 5: Does it survive the aesthetic-stripping test? (Remove the
  narrative beauty — is the bare mechanism still valid?)

## 2. Adversarial Collaboration Protocol (Kahneman)

Origin: Kahneman-Hertwig dispute over the conjunction fallacy. When two
positions are entrenched, polite debate fails. The protocol forces structured
joint investigation.

**Worldbuilding application:** When two interpretations of a canon rule
conflict (e.g., does this physics mechanism apply to all civilizations
or only to magically-attuned ones?):

| Step | Mechanism | Purpose |
|------|-----------|---------|
| Good Faith Articulation | Each side states the opponent's position to the opponent's satisfaction | Eliminates straw-man arguments |
| Co-designed Test | Both sides agree in advance what evidence would resolve the dispute | Prevents post-hoc rationalization |
| Pre-registered Outcome | Both sides agree what result would change their mind BEFORE checking | Eliminates Garden of Forking Paths |
| Joint Resolution | Finding is recorded regardless of which side wins | Ensures truth over ego |

This protocol is especially valuable when the author and Claude Code
disagree about a canon interpretation. Neither side gets to shift
goalposts after checking the evidence.

## 3. Russell Conjugation Stripping

Origin: Bertrand Russell's "emotive conjugation." Synonyms carry identical
factual content but completely different emotional charges:
- "I am firm" (positive)
- "You are obstinate" (neutral)
- "He is pigheaded" (negative)

Same fact. Three different emotional frames. Human decisions often follow
the emotional frame, not the fact.

**Worldbuilding application:** When evaluating lore proposals, strip the
emotive framing before assessing:

| Emotive framing | Neutral restatement |
|-----------------|---------------------|
| "This elegant mechanism unifies..." | "This mechanism connects X to Y via Z" |
| "This beautifully resolves the tension..." | "This removes the contradiction between files A and B" |
| "This rich cultural tradition..." | "This behavioral pattern in civilization X" |
| "This feels deeply wrong for the universe..." | "This contradicts rule N in file Y" |

If the neutral restatement is valid, the lore stands. If it's only
compelling in emotive framing, it fails.

**Detection test:** Rewrite the proposal in the most boring, clinical
language possible. If it still holds, it's mechanistically sound. If it
collapses without the narrative beauty, it was aesthetic, not physics.

## 4. Self-Correction Loop

Origin: Machine learning continuous training. Adapted from agent memory
patterns in autonomous systems.

**Protocol:** When the author corrects Claude Code:
1. Agent acknowledges the error specifically (not generically)
2. Agent proposes a concise, one-line rule to prevent recurrence
3. Author approves → rule appended to CLAUDE.md or agent memory
4. Future sessions avoid the same mistake

**Example:**
- Author: "Don't reference civilization names in science files"
- Agent: "Acknowledged. Proposed rule: 'No civilization or character names
  in physics/ through cognitive-sciences/ except organism nomenclature.'"
- Author approves → added to CLAUDE.md rules

This ensures the system gets better over time rather than repeating the
same corrections across sessions.

## 5. Ensemble Thinking (Diversity Prediction Theorem)

Origin: Scott Page's mathematical proof that prediction accuracy depends
equally on individual model accuracy AND model diversity.

Formula: Collective Error = Average Individual Error − Diversity of Models

**Worldbuilding application:** Never evaluate a new lore element through
a single lens. Apply multiple competing frameworks:

| Framework | Question it asks |
|-----------|-----------------|
| Physics audit | Does it violate any foundational constraint? |
| Biological audit | Does it follow established metabolic/ecological rules? |
| Civilizational audit | Is it consistent across all cultures that should be subject to it? |
| Narrative audit | Does it create productive tension or just contradiction? |
| Predictive audit | Can you DERIVE what would happen next from established rules? |
| Aesthetic-stripped audit | Does it hold without narrative beauty? |

If 4+ frameworks agree: high confidence.
If 2-3 disagree: investigate the disagreement — it usually reveals a real issue.
If all agree too easily: suspicion — check for confirmation bias.

## 6. Active Inference / Free Energy Principle (Friston)

Origin: Neuroscience. All living systems minimize "surprise" (Shannon
entropy) by maintaining internal predictive models and acting to confirm
those predictions.

**Worldbuilding relevance:** Claude Code's behavior IS Active Inference.
It has a generative model (the skills, rules, reference files) and acts
to confirm its predictions (writing lore consistent with its loaded
constraints). The failure mode is when precision weighting is miscalibrated:

- **Overconfident priors** → rigid application of rules that should be flexible
  (different civilizations may legitimately differ)
- **Underconfident priors** → accepting lore that violates rules because the
  violation seems "creative" or "interesting"

**Correction:** When the system seems to be overconfident in its rules or
underconfident in its constraints, manually recalibrate by checking whether
the constraint is universal (high precision, must hold) or civilizational
(lower precision, may vary).

## 7. Comprehensive Anticipatory Design Science (Fuller/CADS)

Origin: Buckminster Fuller. Evidence-based, forward-looking methodology for
addressing complex, interconnected problems through designed artifacts rather
than behavioral mandates.

**Worldbuilding application:** When designing new systems, use the
Consequential Analysis Framework — systematically analyze potential outputs
across four quadrants:

| Quadrant | Question |
|----------|----------|
| Anticipated Desired | What good things do we expect? |
| Anticipated Undesired | What bad things do we expect? |
| Unanticipated Desired | What good things might we not have predicted? |
| **Unanticipated Undesired** | **What bad things might we not have predicted?** |

The fourth quadrant is the critical one. It forces the practitioner to
imagine consequences beyond the known issues — the "unknown unknowns"
that often cause the most damage to canon consistency.
