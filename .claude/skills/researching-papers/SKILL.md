# Researching Papers

Search open-access academic sources for real science to ground fictional systems.

## Process

1. Identify the gap or concept needing grounding
2. Search appropriate sources (arXiv, Crossref, PMC, Semantic Scholar)
3. Read and summarize findings with relevance assessment
4. Present findings — hand off to /integrating-research for formalization

## Citations

Use consistent citation format with ## References section.
Each entry includes a one-sentence annotation.
Cited science is canon science — no disclaimers.

## Out of Scope

Does NOT map research onto canon formalism (use /integrating-research).
Does NOT write science files (use /writing-science).
